# 面向决策的产品实验 —— 第一阶段决策契约

> **状态：** 在任何新运行前冻结。本文件为一页式决策契约，非字母编号协议包。它以单一因果产品决策替代 Phase 10/10P 包系列。
>
> **第一阶段仅为资格 / 余量审计。它不是痛点证明，不是产品效果证明，也不是下游 Agent 评估。** 第一阶段不进行任何 provider 或 agent 运行。

## 1. 决策问题

现有的多通道 OpenLocus Fast Context 证据 pack，是否能在客观编码任务结果上相对同预算仅 BM25 基线取得足以证明其成本的改进（时效性与引用校验在两臂间保持恒定）？

## 2. 冻结源码截止点

- **源码截止点（公开）：** `056877ff638d59118e05e046bd30d816e70ba2fb`
- 候选枚举覆盖在该截止点**之前**可达的所有非合并提交。该截止点是公开输出中唯一允许出现的 SHA。

## 3. 估计量（冻结）

现有 OpenLocus 多通道源码上下文交付 **对比** 相同 pack 构建器 / 渲染路径下 **仅 BM25**。

- 时效性与引用校验在两臂间**保持恒定**。
- **这不是因果时效性测试。** 不允许任何时效性因果声明。

## 4. 总体（冻结）

真实历史代码缺陷，需具备：

- 一个**固定的缺陷父提交**，
- **自然的修复前文字**（未编辑的提交信息，或仅在本地图可用时引用先前关联 issue），
- 一个**精确的开发者编写可执行回归测试**。

仅检索标签语料（R14 / R15 / R20 / R26）是**诊断，不是结果任务**。R14/R20 检索标签**不是**任务结果。

## 5. 处理臂与对照臂（冻结，第一阶段无 provider）

两臂复用**相同的现有生产 Fast Context 路径与渲染器**。

| 臂 | 通道 | RRF | 引用 / 时效性 | `max_evidence` | 近似 token 预算 |
|----|------|-----|--------------|----------------|-----------------|
| **处理** | `regex,bm25,symbol,graph` | 是 | 最终校验保持恒定 | 12 | 2000 |
| **对照** | 仅 `bm25` | （单通道） | 相同构建器/渲染器/查询/上限 | 12 | 2000 |

- 若无法在不修改产品代码的情况下完成精确生产调用，该步骤**诚实失败 / 修复**，而非模拟语义。
- 无稀疏 / 无上下文臂。无 BEA。无新检索家族。

## 6. 客观隐藏测试结果（冻结）

- **隐藏 oracle 策略：** 精确的既有测试或开发者新增测试可**原样（逐字节）**移植到仅评分端隔离覆盖层中。
- **禁止：** 新增或编辑的隐藏测试、从修复中合成的期望值、修复 diff 上下文。
- 结果为各臂 pack 下移植的开发者测试的二元通过/失败。

## 7. Agent 对等性（仅第二阶段 —— 第一阶段不执行）

当且仅当第一阶段通过时，第二阶段构建真实的多次轮次配对 agent 框架，复用 provider 门控 / 隐私模式 —— **而非**合成任务/动作机制。两臂共享相同预算、工具与提示，仅检索变体不同，无跨运行记忆且随机化臂序。

## 8. 资格门（冻结）

- **确定性枚举：** 截止点前可达的所有非合并提交，按**从新到旧，再按 SHA**排序。
- **队列：** 前 8 个合格者，**最少 5 个**。在看到 pack 或结果后不可替换。
- 候选过滤：产品源码 + 开发者测试、单一逻辑缺陷、`<=2` 个产品文件且 `<=100` 行产品改动、来自未编辑提交信息的自然修复前文字。排除 docs / protocol / generated / eval-only / test-only / refactor / dependency / migration。
- **不硬编码有利的候选列表。** 任何粗粒度机械预过滤须基于规则且仅报告聚合原因分桶。

## 9. 可复现性门（冻结，逐候选）

仅当候选可被**确定且安全**地校验时方为合格：

- 缺陷父提交 + 覆盖测试 **3/3 失败**且签名稳定，
- 修复提交 + 相同覆盖 **3/3 通过**，
- 相关修复回归 **2/2 通过**，
- 开发者补丁**通过**，
- 空补丁**失败**，
- 每次评分运行 `<= 10` 分钟。

若候选无法被确定且安全地校验，则**以固定原因分桶排除**。**绝不放宽规则以凑足分母。**

## 10. 余量支出门（冻结）—— 不是结果

这是支出门，非产品结果。使用私有的修复相关预像路径（开发者修复改动的产品文件加上父提交中既有的直接源码/配置依赖路径）。

- 仅当同预算 **BM25 遗漏相关路径**且多通道处理**新增了对照中缺失的有效当前证据**，且**渲染 pack 实质不同**时，`G_i = 1`。
- 在 `N = 前至多 8 个合格者`上要求至少 `max(2, ceil(0.4 * N))` 个此类任务，**最少 `N = 5`**。
- 附加检查：引用再物化、处理无退化、每任务五次预热检索重复、检索 `p95 <= 3s`、**至少一次隔离扫描且隔离扫描失败为零**。

## 11. 实时 GO / STOP 阈值（冻结，第二阶段 —— 仅当第一阶段通过）

仅当**全部**满足时 GO：

- 对照有 `>= 2` 个未解，
- 仅处理胜 `>= 2`，
- 仅对照胜 `= 0`，
- 绝对通过增益 `>= 0.25`，
- `>= 2` 个胜出有运行前 pack 差异，
- 处理检索 `p95 <= 3s`，
- 提示 token `<= 1.10x`，
- 端到端成本 `<= 1.20x`，
- 零隔离 / 引用失败。

**任一 GO 条件失败即终态 STOP。** 不重新设计任务、不替换更易候选、不改阈值、不新增 BEA 版本、不增加臂、不延续包。

内部 GO 仅授权**一次**不变的 Defects4J 确认，覆盖 `>= 3` 个项目。两屏须**独立**通过后才能进行一次有界的可选集成。
